# 多光谱蓝牙通信协议 V4 实现说明

## BLE 通道

- 设备名：`SpectraVita`
- 服务：`0xFEE0`
- APP 向设备写命令：`0xFEE2`（Write Command）
- 设备向 APP 回传：`0xFEE4`（Notify，测试前必须打开通知）
- 完整帧：`AA CMD DATA XOR BB`，多字节数字按小端序排列。
- `0x45` 的 FIFO 回包为 260 字节完整帧，手机端 ATT MTU 需要至少 263。固件连接后会主动请求 MTU 交换。

## 已实现命令

| 请求 | 响应 | 功能 | 响应 DATA 长度 |
| --- | --- | --- | ---: |
| `0x40` | `0x41` | 时间戳、电量、版本 | 6 |
| `0x42` | `0x43` | AS7341 多光谱 | 22 |
| `0x44` | `0x45` | AS7341 FIFO | 256 |
| `0x46` | `0x47` | AS7331 紫外 | 8 |
| `0x48` | `0x49` | WH4530A 接近 | 4 |
| `0x4A` | `0x4B` | ADXL345 加速度 | 6 |
| `0x4E` | `0x4F` | 启动周期采集 | 1 |
| `0x50` | `0x51` | 上传指定传感器历史数据 | 4 + N |
| `0x52` | `0x53` | 停止周期采集 | 0 |

协议表格和命令说明对 `0x43`、`0x49` 的长度描述不一致。本固件按照当前约定实现为 22 字节和 4 字节。

`0x4E` 中每种传感器的 X 按“实际周期 = 最小采集周期 × X”实现；X 为 0 时不采集该传感器。收到新的 `0x4E` 会清空已有历史数据。历史上传期间暂停触发新的周期采集，发送队列清空后自动恢复。

紫外 GAIN 当前按 AS7331 的 0～11 档解释，依次对应 1x～2048x；越界时使用 512x。接近传感器第一个数据使用命令中的低 2 位增益，第二个数据保留原工程的增益 3，以便形成 A/B 两组数据。

## 串口/手机快速测试帧

下面均为 HEX 发送：

- 查询设备：`AA 40 40 BB`
- 多光谱（ATIME=29，ASTEP=599，AGAIN=10）：`AA 42 1D 57 02 0A 00 BB`
- FIFO（FD_TIME=720，GAIN=5）：`AA 44 D0 02 05 93 BB`
- 紫外（GAIN=9）：`AA 46 09 4F BB`
- 接近（GAIN=0）：`AA 48 00 48 BB`
- 加速度：`AA 4A 4A BB`
- 上传多光谱历史：`AA 50 01 51 BB`
- 停止周期采集：`AA 52 52 BB`

烧录文件：`output/app/bk3633_app_merge_crc.bin`。

## 低功耗处理

- 无采集任务时关闭 `VDD_1P8_PIN` 和 `VDD_SENSOR_PIN` 电源域。
- AS7331 测量后进入 Power Down，ADXL345 测量后进入 Standby，AS7341 完成后关闭测量模块。
- 不再默认每秒连续采集；只有收到单次读取或 `0x4E` 后才工作。
- 连接指示灯只短闪，不在整个连接期间常亮。
- BLE 广播仍使用约 2 秒间隔，连接参数使用 75～100 ms 间隔和 slave latency 4。
